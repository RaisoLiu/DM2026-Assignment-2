\textbf{Best C = 100} (selected by highest validation accuracy = 95.5\%).

The best parameter is selected using the validation set rather than the test set. For each candidate $C$, we train the SVM on the training set and compare its validation accuracy and macro-F1 score. The validation curve in Figure~\ref{fig:svm-sweep} reaches its maximum at $C=100$, with validation accuracy 95.5\% and validation macro-F1 95.4\%. This divergence indicates that larger $C$ values fit the training data more tightly without improving generalization. Therefore, $C=100$ is chosen as the best parameter before checking the final test-set result.

\begin{figure}[H]
\centering

\begin{itemize}
    \item \textbf{Underfitting at small C:} With $C \leq 0.01$, the SVM's decision boundary is overly constrained, yielding accuracy near random chance (25\% for 4 classes). The margin is too wide and misclassifies most samples.
    \item \textbf{Training improves after C=100, but validation declines:} Increasing $C$ beyond 100 weakens regularization, so the classifier fits the training data more aggressively. This raises training accuracy, but validation accuracy decreases, meaning the extra flexibility does not transfer to unseen validation samples. This widening train--validation gap is a classic overfitting signal.
    \item \textbf{Errors are mostly ordinal-neighbor mistakes:} The confusion matrix shows only 12 test errors out of 400 samples. They occur between neighboring classes (0/1, 1/2, 2/3), which is expected because \texttt{price\_range} is an ordered label.
\end{itemize}

This is not an apples-to-apples comparison, but it highlights that label information is critical for this classification task.
\end{itemize}

\section{Q5: Enhancing K-Means with Lift-Sum Feature Weighting}
%==============================================================================

\subsection{Motivation}

The Q4 result shows the core problem: standard K-Means gives every standardized feature equal weight in Euclidean distance, yet its clusters are almost unrelated to the true \texttt{price\_range} labels (ARI $=0.0058$ on average). This suggests that equal weighting lets weak or irrelevant features dilute the few features that actually carry price-range signal.

The Q2 RBF-SVM provides a supervised reference for this feature-importance imbalance. Because the validation-selected RBF-SVM ($C=100$) has no direct linear coefficient vector, we use permutation importance on the Q2 test set: each feature is shuffled repeatedly, and the resulting drop in test accuracy is measured. Figure~\ref{fig:q5-svm-importance} shows that \texttt{ram} dominates the SVM's prediction behavior, followed by \texttt{battery\_power}, \texttt{px\_width}, and \texttt{px\_height}. This motivates replacing equal K-Means distances with a feature-weighted distance.

\begin{figure}[H]
\centering
\includegraphics[width=0.78\textwidth]{figures/q5_svm_permutation_importance.png}
\caption{Permutation importance of the Q2 RBF-SVM ($C=100$). The largest accuracy drop occurs when \texttt{ram} is permuted, showing that the supervised model relies on highly uneven feature importance rather than equal feature contribution.\label{fig:q5-svm-importance}}
\end{figure}

\subsection{Lift-Sum Feature Importance}

The rewritten Q5 uses association-rule lift as a second feature-importance signal. The method is \textbf{semi-supervised}: \texttt{price\_range} labels are used during class-stratified rule mining, while the final K-Means clustering step itself remains unsupervised.

\begin{figure}[H]
\centering
\includegraphics[width=\textwidth]{figures/q5_method_flowchart.png}
\caption{Rewritten Q5 method design. Equal-weight K-Means motivates feature weighting; Q2 SVM permutation importance provides a supervised reference; class-stratified FP-Growth produces lift sums; normalized lift sums are used as K-Means feature weights; random reassignment tests whether the feature-to-weight mapping matters.\label{fig:q5-method-flowchart}}
\end{figure}

Each original feature is discretized with the same 3:4:3 range split used earlier:
\begin{align*}
\text{low} & : [\min, \min + 0.3\,\text{range}], \\
\text{medium} & : (\min + 0.3\,\text{range}, \min + 0.7\,\text{range}], \\
\text{high} & : (\min + 0.7\,\text{range}, \max].
\end{align*}
Then FP-Growth is run separately inside each \texttt{price\_range} class using \texttt{min\_support=0.3}. Association rules are retained when confidence $\geq 0.5$ and lift $\geq 1.0$. For each original feature $f$, we sum the lift values of all retained rules that contain any discretized item derived from $f$:
\[
\mathrm{LiftSum}(f) = \sum_{r:\, f\in r} \mathrm{lift}(r).
\]
The lift sums are converted to feature weights in the range $[1,3]$:
\[
w_f = 1 + 2 \cdot \frac{\mathrm{LiftSum}(f)}{\max_g \mathrm{LiftSum}(g)}.
\]
The highest lift-sum features are \texttt{ram} (295.34, weight 3.00), \texttt{three\_g} (259.75, weight 2.76), \texttt{fc} (193.09, weight 2.31), \texttt{four\_g} (118.57, weight 1.80), and \texttt{px\_height} (54.23, weight 1.37).

\subsection{SVM vs. Lift-Sum Comparison}

Figure~\ref{fig:q5-svm-lift-comparison} compares normalized SVM permutation importance and normalized lift sum. The agreement is meaningful but not perfect. Across all 20 features, Pearson correlation is moderate ($r=0.535$, $p=0.015$), while rank correlation is weak (Spearman $\rho=0.156$, $p=0.510$). When binary features are excluded, Pearson correlation rises to $r=0.744$ ($p=0.002$), indicating that lift sums are more aligned with the SVM signal among the continuous and non-binary features. The strongest agreement is the most important one: both methods identify \texttt{ram} as the dominant feature.

\subsection{Weighted PCA Analysis}

To visualize the effect of lift-derived weights, we multiply the standardized feature matrix by the lift weights and then run PCA:
\[
X_{\mathrm{weighted}}[:, f] = X_{\mathrm{scaled}}[:, f] \cdot w_f.
\]
Figure~\ref{fig:q5-weighted-pca} shows the PCA projection after weighting. The first two weighted PCs explain 39.2\% of the variance, compared with only 16.5\% for the original 2D PCA in Q4. The price-range ordering becomes more visible, especially along the weighted PCA bands, although the classes still overlap. This supports the claim that lift-based weighting improves the geometry, but does not make the problem linearly separable.

\begin{figure}[H]
\centering
\includegraphics[width=\textwidth]{figures/q5_lift_weighted_pca.png}
\caption{PCA 2D projection after applying class-stratified lift-derived feature weights, with the top feature lift sums shown beside it. PCA is fitted on weighted standardized features; true \texttt{price\_range} labels are shown only for interpretation.\label{fig:q5-weighted-pca}}
\end{figure}

\subsection{Randomization Ablation}

The ablation study tests whether improvement comes from the correct feature-to-weight mapping or merely from having an uneven set of weights. The correct method assigns each lift-derived weight to its original feature. The random baseline preserves exactly the same weight values, but randomly permutes them across features before running K-Means. We use 20 random permutations and 5 K-Means seeds \{0, 10, 42, 100, 999\}, yielding 100 random evaluations.

\subsection{Conclusion}

Q5 therefore changes from a broad feature-engineering experiment into a focused feature-weighting argument. Equal-weight K-Means fails because it treats all standardized features as equally useful. Q2 SVM permutation importance confirms that the actual prediction signal is highly uneven. Class-stratified association-rule lift sums recover part of this feature-importance structure, most clearly for \texttt{ram} and several non-binary features. Applying these lift-derived weights improves both the PCA geometry and K-Means ARI, and the randomization ablation shows that the correct feature-to-weight assignment is essential.
