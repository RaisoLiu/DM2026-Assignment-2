This confirms that 5-fold CV on this dataset provides a reliable estimate of out-of-sample performance.
    \item The top-1 model shows higher recall (84.2\%) than precision (72.7\%), meaning it favors identifying positive samples at the cost of more false positives.
\end{itemize}

\[
\text{low} \leq \min + 0.3 \times \text{range}, \quad
\text{medium} \leq \min + 0.7 \times \text{range}, \quad
\text{high} > \min + 0.7 \times \text{range}

The discretized features are converted to a boolean one-hot transaction matrix ($500 \times 12$).

\section{Q5: Enhancing K-Means with Association Rule Mining (35 pts)}
%==============================================================================

\subsection{Motivation and Inspiration}

Standard K-Means treats all features equally and cannot distinguish discriminative features from noise. We propose a \textbf{semi-supervised} enhancement that uses association rule mining to guide clustering. The approach explicitly leverages class labels during feature engineering, while K-Means itself remains unsupervised.

\textbf{Inspirations:}
\begin{itemize}[nosep]
    \item \textit{TF-IDF-style feature importance}: We adapt the idea of term specificity (IDF) to use association rule lift as a proxy for discriminative power. Features that appear in high-lift rules for specific classes are analogous to terms with high IDF --- they carry more information.
    \item \textit{Supervised discretization} (Fayyad \& Irani, 1993): Class labels guide the mining process to identify feature patterns that maximize class separability, similar to how supervised binning optimizes split points.
    \item \textit{Feature augmentation for clustering}: Enriching the feature space with auxiliary pattern-based features before applying standard clustering, as discussed in lecture on pattern-based clustering.
\end{itemize}

\subsection{Method Design}

\begin{enumerate}
    \item \textbf{Rule-Guided Feature Weighting (semi-supervised):} All 20 features are discretized (3:4:3 value range split) and association rules are mined \textit{per class} using FP-Growth (\texttt{min\_support=0.3}, confidence $\geq 0.5$, lift $\geq 1.0$). For each original feature, we accumulate the lift values from all rules in which the feature appears across all classes. The resulting importance scores are normalized to weights in $[1.0, 3.0]$ and applied to the standardized features. This step is explicitly label-guided.
    \item \textbf{Class-Stratified Pattern Features (semi-supervised):} The top 5 most discriminative patterns (ranked by lift $\times$ confidence) are selected from each class's rules, yielding 20 binary features indicating whether a sample matches each class-associated itemset.
\end{enumerate}

The augmented feature matrix combines 20 weighted original features with 20 scaled pattern features (40 total).

\subsection{Evaluation Protocol}

All variants are evaluated using the same protocol:
\begin{itemize}[nosep]
    \item 5 random seeds: \{0, 10, 42, 100, 999\}
    \item \textbf{Hungarian algorithm} (\texttt{scipy.optimize.linear\_sum\_assignment}) maps cluster IDs to true labels optimally before computing accuracy, precision, recall, and F1 (all macro-averaged).
    \item \textbf{Clustering-native metrics}: ARI (Adjusted Rand Index) and NMI (Normalized Mutual Information) are also reported, which do not require Hungarian mapping.
\end{itemize}

\subsection{Analysis}

\begin{itemize}
    \item \textbf{Feature weighting is the dominant component.} The weighting-only variant achieves the best accuracy (44.2\%) and ARI (0.177), outperforming even the full method (38.9\%, ARI=0.101). This reveals that \texttt{ram} (weight=3.0), \texttt{three\_g} (2.76), and \texttt{fc} (2.31) are the key discriminative features, and simply upweighting them provides the largest clustering improvement (+14.6 pp accuracy over baseline).
    \item \textbf{Pattern features alone hurt performance.} The pattern-only variant (26.2\%) performs \textit{worse} than baseline (29.6\%), with ARI near zero. This indicates that appending 20 binary pattern features to the 20 original features introduces noise that dilutes the continuous feature signal. The discrete pattern features create artificial cluster structure that does not align with the true classes.
    \item \textbf{The full method is a compromise.} Combining weighting and patterns (38.9\%) is better than baseline but worse than weighting alone. The pattern features partially counteract the benefit of feature weighting by adding noisy dimensions. This is a valuable negative finding: \textbf{more features is not always better}, even when those features encode class-related information.
    \item \textbf{Clustering-native metrics confirm the trend.} ARI and NMI follow the same ranking as classification metrics (weighting-only $>$ full $>$ baseline $>$ pattern-only), providing evidence that the cluster \textit{structure itself} improves, not just the post-hoc label mapping.
    \item \textbf{Limitations.} Even the best variant (44.2\%) remains far below supervised SVM (97\%). K-Means cannot capture non-linear decision boundaries regardless of feature engineering. The semi-supervised nature of this approach (using labels for rule mining) is also a limitation for purely unsupervised settings.
\end{itemize}
